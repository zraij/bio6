# أحياء السادس العلمي

شرح تفاعلي لفصول كتاب الأحياء للصف السادس العلمي الخمسة: مجسمات ثلاثية الأبعاد، مختبر تفاعلي، التعاريف والمسائل المهمة وحلها، وتحدّي الفرق.

- **الموقع:** https://zraij.github.io/bio6/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/bio6/admin.html (لصاحب الموقع فقط)

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة. كل حساب أستاذ يُقفل على أول جهاز يدخل منه، وحساب المدير مستثنى من القفل.
